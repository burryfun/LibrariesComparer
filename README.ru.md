# LibrariesComparer

**LibrariesComparer** — Утилита на .NET 8 для анализа зависимостей проектов (NuGet и локальных DLL), сравнения с предыдущими снэпшотами и генерации отчетов (JSON, Excel, HTML).

## Возможности

- Рекурсивный поиск всех `.csproj` файлов в указанной папке.
- Извлечение NuGet-пакетов (`PackageReference`) и локальных DLL (`Reference`).
- Получение информации о версиях, датах выпуска, уязвимостях, деприкации.
- Сравнение с предыдущим снэпшотом:
  - Новые библиотеки - зелёный цвет.
  - Изменённые версии - жёлтый цвет.
  - Удалённые - красный цвет.
  - Без изменений - белый цвет.

## Пример запуска

```sh
dotnet run "dirpath"
```

После выполнения в папке `snapshot` появятся файлы:
   - `yyyy_MM_dd_HH-mm.json` - актуальный снэпшот зависимостей
   - `.html`, `.xlsx` - отчёты сравнения с предыдущей версией
